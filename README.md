Executive Revenue & Sales Performance Dashboard

📌 Overview
An executive-level sales performance dashboard built using Microsoft Excel This project analyzes multi-year retail datasets to track overall revenue, store performance, and key operational metrics with an intuitive UX/UI design.

🛠️ Tools & Technologies
- Microsoft Excel (Data Modeling, Advanced Pivot Tables, Dynamic KPIs, Excel Formulas)
- Data Visualization & UX/UI Design

💡 Key Features & Insights
- Evaluated multi-year retail revenue and overall sales growth.
- Developed dynamic KPIs to track store-level operational metrics and revenue targets.
- Designed a streamlined UX/UI dashboard layout for quick executive insights and decision-making.
